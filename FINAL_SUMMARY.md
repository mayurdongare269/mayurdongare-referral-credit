## 🎯 User Flow

### New User Journey
1. **Land on homepage** → See professional design, stats, features
2. **Scroll to "How It Works"** → Understand the system
3. **Browse courses** → No sign-in required, search & filter
4. **Find interesting course** → Click "Enroll Now"
5. **Sign in prompt** → Quick Clerk authentication
6. **Purchase course** → Earn 2 credits (or 4 if referred)
7. **Get referral link** → Share with friends
8. **Track progress** → Dashboard shows real-time stats

### Referral Flow
1. **User A** signs up → Gets referral link
2. **User A** shares link → Friend clicks
3. **User B** browses courses → Finds one they like
4. **User B** signs up → Using referral link
5. **User B** purchases → Gets 4 credits (2 + 2 bonus)
6. **User A** gets 2 credits automatically
7. **Dashboard updates** → Real-time stats for both
